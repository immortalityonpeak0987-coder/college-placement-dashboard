# Campus Placement Analysis: Mumbai & Pune Colleges

End-to-end data analysis project: raw, messy placement files → cleaned dataset → interactive dashboard website.
Built with **Python (pandas)** for cleaning and analysis, and **HTML/CSS/JavaScript + Chart.js** for the dashboard, hosted on Vercel.

**Live demo:** _https://college-placement-dashboard-kdnxnaxen-immortal-silent.vercel.app_

![Dashboard preview](docs/dashboard-preview.png)

## Why this project
Placement data usually arrives as several overlapping, inconsistent files. The goal was to turn it into something a junior student can act on, by answering three questions:

1. **What does a typical package look like?** Average vs median package (LPA) by region.
2. **Which companies recruit most often?** Top 10 by placement records and number of colleges.
3. **How do placements change year over year?** Placements per year (2014 to 2018) next to the number of colleges reporting.

## Pipeline at a glance
```
data/raw (7 CSVs)
   → 01_clean_data.py              drop junk rows, remove duplicates, package → LPA
   → 02_propose_company_mapping.py suggest company-name merges (for human review)
   → 03_merge_company_names.py     apply reviewed merges, re-deduplicate
   → 04_export_dashboard_data.py   compute dashboard numbers → assets/data.js
   → index.html                    interactive dashboard
```

- [`data/raw/`](data/raw/): 7 raw source CSV files ([README](data/raw/README.md))
- [`scripts/01_clean_data.py`](scripts/01_clean_data.py): Drop header junk rows, normalize text casing, remove duplicates, calculate LPA
- [`scripts/02_propose_company_mapping.py`](scripts/02_propose_company_mapping.py): Propose merges for inconsistent company names using fuzzy matching
- [`scripts/03_merge_company_names.py`](scripts/03_merge_company_names.py): Apply reviewed merges and re-deduplicate
- [`scripts/04_export_dashboard_data.py`](scripts/04_export_dashboard_data.py): Compute metrics and export to [`assets/data.js`](assets/data.js)
- [`index.html`](index.html): Interactive Chart.js dashboard

Details of the raw files are in [`data/raw/README.md`](data/raw/README.md).

| Colleges | 27 |

| Highest average package | Mumbai: 7.16 LPA (median 6.42) |
| Pune | average 6.67 LPA, median 4.83 |
| Most frequent recruiters | L&T Infotech, Capgemini, Infosys, Syntel, Tech Mahindra |
| Placements per year | 2014: 21, 2015: 206, 2016: 265, 2017: 299, 2018: 1,958 |

**Reading the results:** averages are pulled up by a few high packages, so the median is a better guide to what is typical. The jump in 2018 mostly reflects more colleges appearing in the data (24 in 2018 vs 2 in 2014), not necessarily real growth.

## Data cleaning steps
- Removed header rows that leaked into the data and exact duplicate records.
- Normalised company, college and region text (trim, collapse whitespace, upper-case).
- Converted package strings into one numeric **LPA** column (yearly values ÷ 100,000; monthly values × 12 first). Rows in other units are left empty.
- Standardised company names: formatting-only variants merged automatically; typo-like pairs merged after manual review; pairs judged to be different companies or divisions were left unmerged (see `RISKY` in [`scripts/03_merge_company_names.py`](scripts/03_merge_company_names.py)).
- Removed duplicates created by the name merge.

## Skills demonstrated
Multi-file data profiling and reconciliation, duplicate and near-duplicate detection (pandas, difflib), unit normalisation, human-in-the-loop data cleaning, reproducible scripts, and dashboard design with Chart.js.

## Limitations
- Package data exists for only 399 of 2,749 records, so package averages are less reliable.
- The dataset has **no branch column**, so results are by region and college.
- Package source is [`data/raw/variation_3.csv`](data/raw/variation_3.csv) (explicit units). [`data/raw/detailed_data.csv`](data/raw/detailed_data.csv) disagrees with it on about 107 rows and was not used.
- Some company spelling variants remain unmerged (the matching threshold was kept strict to avoid false merges).
- This is a sample/dummy dataset used for demonstration.

## Run it locally
```bash
pip install -r requirements.txt
python3 scripts/01_clean_data.py
python3 scripts/02_propose_company_mapping.py
python3 scripts/03_merge_company_names.py
python3 scripts/04_export_dashboard_data.py
python3 scripts/05_build_preview.py   # optional
```
Then open [`index.html`](index.html) in a browser (internet needed for Chart.js and Google Fonts).

## Deploy on Vercel
1. Push the repository to GitHub.
2. On vercel.com choose **Add New → Project** and import the repo.
3. It is a static site with [`vercel.json`](vercel.json) included, so no build command is needed. Deploy, then paste the URL at the top of this README.
